四个功能，只做取色这一件事

没有账号、没有历史记录、没有后台请求，装上就能用。

系统级取色

调用浏览器原生 EyeDropper API，可以直接吸取屏幕上任意位置的颜色，包括图片、视频与其他窗口。

自动复制

取色成功后立刻把 HEX 色值写进剪贴板，切回代码里直接 Ctrl+V 就能用。

HEX + RGB

同时给出两种色值格式，并带一块颜色预览，方便快速判断对比度与明暗。

零数据外传

不申请任何网络权限，不写本地存储，取完色即结束。唯一权限是 activeTab。

常见问题

为什么点「开始取色」会先弹出一个小窗口？

直接在小弹窗里调用 EyeDropper 时，浏览器会把焦点交给全屏取色层， 工具栏弹窗会被系统关闭，取色结果就取不回来了。所以插件改为打开一个独立小窗口来取色， 窗口不会消失，取完能立刻看到色值并自动复制。

支持哪些浏览器？

需要支持 EyeDropper API 的浏览器，也就是 Chrome 95+、Edge 95+ 及以上版本。 在旧版浏览器或不支持的浏览器里打开插件，会直接看到「浏览器不支持」提示，不会报错。

取色时可以取消吗？

可以。取色状态下按 ESC 即可退出，插件会提示「已取消本次取色」，原有颜色不受影响。

插件会上传我的数据吗？

不会。插件没有申请任何网络权限，也不使用 localStorage 或 chrome.storage， 所有逻辑都在本地弹窗里完成，取到的颜色用完即弃。

复制失败怎么办？

极少数情况下浏览器会拦截自动写入剪贴板。此时点击「复制色值」按钮手动复制即可， 两种方式写入的内容完全一致。
